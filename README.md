# 초성 퀴즈 – 서버 (게임 + 사전 연동)

이 폴더 하나로 게임 화면과 사전 API 연동이 모두 됩니다. `public/index.html`이 게임이고,
`server.js`가 인증 키를 안전하게 보관하면서 사전에 대신 물어봐 주는 역할을 합니다.

## 컴퓨터에서 매번 켤 때 (더블클릭)

`게임서버켜기.bat` 파일을 더블클릭하세요. 검은 창이 뜨고 서버가 켜지면
`chosung-quiz.html` 대신, 브라우저에서 아래 주소를 열면 됩니다.

```
http://localhost:3000
```

(이렇게 열면 "프록시 서버 주소" 칸을 입력할 필요 없이 자동으로 사전과 연동됩니다.)

## 처음 설치할 때

```bash
npm install
cp .env.example .env
# .env를 열어 STDICT_KEY에 발급받은 인증 키를 넣기
npm start
```

## 인터넷에 올려서 블로그에 링크하기 (배포)

지금은 본인 컴퓨터가 켜져 있을 때만 작동해요. 미문사 블로그에서 누구나 클릭 한 번으로
쓸 수 있게 하려면, 이 폴더 전체를 무료 호스팅 서비스에 올려서 "항상 켜져 있는 인터넷 주소"를
만들어야 합니다. 추천 순서:

1. **Render** (render.com) 같은 무료 호스팅에 이 폴더를 올린다.
2. 환경변수에 `STDICT_KEY`를 등록한다 (`.env` 파일 내용과 동일하게).
3. 배포가 끝나면 `https://무언가.onrender.com` 같은 주소가 생긴다.
4. 그 주소를 미문사 블로그 글에 링크나 버튼으로 걸어 두면, 클릭 한 번으로 게임이 열린다.

이 단계는 계정 만들기 등 몇 단계가 더 필요해서, 원하시면 하나씩 도와드릴게요.

## 파일 구성

- `게임서버켜기.bat` — 더블클릭으로 서버 켜는 실행 파일
- `server.js` — 서버 본체 (게임 화면 서빙 + 사전 API 연동 + 24시간 캐시)
- `public/index.html` — 게임 화면 (서버가 자동으로 이 파일을 보여줌)
- `package.json` — 의존성 (express, cors, dotenv)
- `.env.example` — 환경변수 예시 (실제 키는 절대 공개 저장소에 올리지 않기)
